# Code of Conduct

## Our pledge

ShipClear exists to help people who are new to software security. That spirit extends to this community: we welcome everyone — from first-time contributors to security veterans — and we treat questions that might seem basic as exactly the questions this project exists to answer.

## Our standards

**Expected:**
- Be patient and generous with newcomers; explain, don't gatekeep.
- Give feedback about code and ideas, never about people.
- Assume good intent; ask before concluding.

**Not tolerated:**
- Harassment, insults, or discrimination of any kind.
- Mocking anyone for a security mistake or for not knowing something. (People come here *because* of security mistakes. That's the point.)
- Publishing others' private information.

## Enforcement

Violations can be reported to **adamtimmerberg@gmail.com**. Reports are handled confidentially. Maintainers may remove comments, reject contributions, or ban contributors for behavior that violates this code.

Adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/), v2.1.
